Make a Bybit key 3 mins

  1. Open bybit.com in a browser on a computer. Click your profile icon, then API.
  2. Click Create New Key, then System-generated API Keys.
  3. Choose API Transaction and name it Bots.
  4. Pick Read-Write.
  5. In the IP box, paste 130.210.43.225. That's the bot server, so the key won't work anywhere else, even if someone copies it.
  6. Under Unified Trading, tick Contract: Orders and Positions. Leave every other box empty.
  7. Confirm with your 2FA code. Copy the key and the secret now: Bybit shows the secret only once.

The key canopen and close futures trades and set their stop-losses.

The key can'twithdraw or transfer anything. You left those boxes empty, so it has no power to move money.

You canwithdraw, close a trade or delete the key whenever you like. Delete it and the bots stop.
