# urelimitless logo

**The idea in one sentence:** an infinity ribbon that grows from a fine line into a bold arrow and breaks out of its own loop, carrying AI (the circuit) and business growth (the bars): companies that grow beyond their limits.

Tagline: **GROW BEYOND LIMITS**

## Which file do I use?

| Where | File | Notes |
|---|---|---|
| Profile picture (LinkedIn, X, Telegram, WhatsApp, Instagram) | `urelimitless-app-icon-512.png` | Always the **icon**, never the full logo. The avatar test showed the name can't be read in any circle under 96px. |
| Website header, desktop | `urelimitless-lockup-horizontal-dark.svg` (dark site) or `-light.svg` (light site) | Use at 150px wide or more. Under 150px, use the icon. |
| Website header, mobile | Same horizontal file, around 190px wide | |
| Browser tab icon | `favicon.svg` (plus `favicon-32.png` for old browsers) | A heavier version made to survive 16px. |
| Hero, cover slide, poster, merch | `urelimitless-lockup-stacked-dark.svg` / `-light.svg` | The full emblem with name and tagline. Needs at least about 200px of width. |
| Email signature | `urelimitless-lockup-horizontal-light.svg` at about 170px wide | |
| Video intro, website hero animation | `urelimitless-lockup-animated.svg` (with name) or `urelimitless-emblem-animated.svg` | Draws from the hairline to the arrow tip, then the name rises in (about 2.7s). People with reduced motion turned on see the finished logo. |
| Documents, slides, Canva (no SVG support) | `urelimitless-lockup-stacked-dark.png` / `-light.png`, `urelimitless-emblem-transparent.png` | |
| Print, stamps, embroidery, engraving, one colour only | `urelimitless-lockup-stacked-black.svg` or `-white.svg`, `urelimitless-emblem-black.svg` | Send the printer the **SVG**. Ask for a physical sample before a large run, because the hairline start of the ribbon is the finest detail and should be checked on fabric. |
| Optional red colourway (like the reference you liked) | `urelimitless-lockup-stacked-red.svg` / `.png` | |

File names: **emblem** is the symbol alone, **icon** is the simplified symbol for small sizes, **lockup** is the symbol with the name. Colours: **dark** means "for dark backgrounds" (cream logo), **light** means "for light backgrounds" (black logo).

## Colours

| Name | Hex | Use |
|---|---|---|
| Bakelite | `#1d1b19` | Dark backgrounds |
| Cream | `#efe6d6` | Logo on dark |
| Ink | `#16130f` | Logo on light |
| Lamp amber | `#e8b52f` | Accent on dark (tallest bar, icon arrowhead) |
| Signal red | `#d9452f` | Accent on light, and the optional red colourway |

Fonts: Big Shoulders Display 700 (name) and Barlow Condensed 600 (tagline). Both are free (Google Fonts). The SVGs already have the text converted to outlines, so they display correctly without the fonts installed.

## How it was tested

- `urelimitless-logo-tests.png`: scale from 128px down to 16px, blur, no name, grayscale, inverted, one colour, light mode, horizontal.
- `urelimitless-in-context.png`: avatar circles at real app sizes, a Telegram chat list, a mobile website header, a browser tab, an email signature.
- Clean geometry: the ribbon is built from about 74 anchor points with smooth curves (it was 694 in the first draft).

## Honest note on ownability

Circuit lines, bar charts and up-arrows are among the most common images in "AI" and "business growth" logos. On their own, they would not set urelimitless apart. What is ownable here is the **ribbon that grows from a hairline and breaks out of its own infinity loop into an arrow**. That's why the icon (the version people will see most, as a profile picture) keeps only the ribbon and the arrow.

Before you print anything, run these quick tests with real people (they take 10 minutes):

1. **Lineup test:** put the icon next to 15 to 20 logos of other AI agencies, all the same size, with the names covered. Does your eye land on it?
2. **5-second test:** show the logo to 3 to 5 people for 5 seconds, hide it, then ask them to pick it out of a lineup. If several pick the same wrong logo, compare the two.
3. **Feeling test:** show it without explaining, and ask "what three words does this make you feel?" You want words like *growth, smart, unlimited, forward*. If you hear *glasses, maths, finance app*, tell me.

## Rebuilding

The logo is generated by code in `src/` (`system.py` builds every file, `emblem.py` holds the shape, `context.py` the in-context sheet). Change a number there and rebuild, rather than editing the SVGs by hand. The rejected first version (the equal-loop infinity that looked like glasses) is kept in `_v1-infinity-rejected/`.
